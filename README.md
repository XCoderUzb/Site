# AniManxwa Creator (sayt yaratuvchi)

1. GitHub'da repo yarating: `AniManxwa-Ctreator` (public). Shu 5 faylni ildizga yuklang: `index.html`, `404.html`, `config.js`, `style.css`, `app.js`.
2. Settings -> Pages -> main / root.
3. `config.js` dagi `API` ga Render server manzilini yozing.
4. Google Cloud -> Credentials -> OAuth client -> Authorized JavaScript origins: `https://xcoderuzb.github.io`.
5. Server repo'siga yangi `server.js` ni yuklang (Render o'zi qayta joylaydi).

Havolalar: `https://xcoderuzb.github.io/AniManxwa-Ctreator/Mangalar-Olami/` (bosh sahifa), `.../Mangalar-Olami/manhwa/manga-nomi/1` (bob).
Domen olingach `config.js` da `DOMAIN` ni yozing: saytlar `nom.domen` da ham ochiladi, eski havolalar ham ishlayveradi.
